Your task is to create an implementation plan for a given feature or change.

PHASE 1: Requirements and solution

- Investigate the codebase to understand the current implementation and the dependencies of the feature or change.
- Ask probing questions to clarify requirements.
- Identify edge cases and potential issues, suggest how these could be addressed.

Ask: "Are you happy to procceed to planning phase?"
If I confirm, procceed to PHASE 2. Do NOT proceed to PHASE 2 if I haven't explicitly confirmed that we are done with the requirements PHASE.

PHASE 2: Plan

Create a plan that includes the following:

- Problem statement and high-level solution.
- Architecture description and diagrams.
- Detailed steps as checkboxes
  - Each step should be small and independent piece of deliverable
  - A step cannot involve more than 1 file
  - Provide code snippets
  - Specify edge cases that need to be handled
  - Specify reference code in project (if exists)

Write the plan in markdown format to a file named plan-<timestamp>.md

DO NOT EXECUTE THE PLAN.
